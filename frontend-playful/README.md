# frontend-playful

Full **Playful** skin of Upvex (individuals demo).

- Local: `npm install && npm run dev` → http://localhost:5173
- Railway: Root Directory `/frontend-playful`, config `frontend-playful/railway.toml`
- Same API as `frontend-soft` via `VITE_API_URL`

Design reference: [`../designs/design-playful-corporate-soft.html`](../designs/design-playful-corporate-soft.html) (left column).
