# frontend-soft

**Softened Playful** skin of Upvex (corporate demos).

- Local: `npm install && npm run dev` → http://localhost:5174
- Railway: Root Directory `/frontend-soft`, config `frontend-soft/railway.toml`
- Same API as `frontend-playful` via `VITE_API_URL`

Design reference: [`../designs/design-playful-corporate-soft.html`](../designs/design-playful-corporate-soft.html) (right column).
